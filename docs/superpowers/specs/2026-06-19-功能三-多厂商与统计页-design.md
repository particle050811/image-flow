# 功能三：通用多厂商 + 统计页 — 设计

> 状态：**设计稿，待审阅**。本文只给设计与数据模型，不含实现代码；外部接口对接以「收集 API 文档」为交付物。
> 日期：2026-06-19 ｜ 路线图索引见 `2026-06-19-三功能路线图-design.md`

## 现状锚点（代码事实）

- API 层（`src/api.ts`）写死 grsai 私有异步协议：`POST /v1/api/generate`（拿 job id）+ 轮询 `GET /v1/api/result`；`baseUrl` 仅两个 grsai 节点（`src/config.ts` `CONFIG_OPTIONS`）。
- grsai 已提供 OpenAI 兼容接口 `/v1/chat/completions`（多模态对话）与 `/v1/images/generations`（同步生图），见 `docs/grsai-api.md`。
- `TaskManager`（`src/tasks.ts`）假设「提交拿 id → 轮询 → 下载」，并发 N 个 job，支持重启续拉。
- `InboundMessage` 的 `navigate` 已预留 `'api'` 标签页（`src/shared.ts:170`）。
- 配置存储：非敏感项进 `globalState`，`apiKey` 进 `secrets`；全项目数据文件统一 JSON。
- 任务级元信息已存 `meta.json`（功能一），含 `model` / `requested` / `succeeded` 等，可供统计复用。

## 目标
1. 让扩展不再绑死 grsai，支持任意 **OpenAI 兼容**中转厂商。
2. 新增统计页，呈现 API 耗时、花费（估算）、调用成功率。

> 顺序提示：本功能内「多厂商抽象」应早于「统计埋点」，以便埋点能记录「来源厂商」。

## 多厂商（通用 OpenAI 兼容层）
- **provider 抽象**：配置从「单一 baseUrl/apiKey/model」升级为**厂商列表 + 当前选中项**。每个 provider 含：
  - `id` / `label` / `baseUrl` / `apiKey`（敏感，进 secrets，按 provider id 分键）/ `protocol`（协议类型）/ `models`（可用模型列表）。
- **两种协议适配器**：
  - `grsai-async`：现有私有异步——`POST /v1/api/generate` 拿 id → 轮询 `GET /v1/api/result`。
  - `openai-images`：标准 `POST /v1/images/generations`，**同步**返回结果（提交即拿图，无 job id、无轮询）。
- **适配层接口**（概念，非代码）：统一为
  - `submit(provider, prompt, images, params) → { kind: 'async', id } | { kind: 'sync', urls }`
  - `query(provider, id) → JobResult`（仅 async 协议用）。
- **TaskManager 适配难点**：现逻辑假设「提交拿 id → 轮询」。同步厂商相当于「提交即终结」，需让 `submitJobs` 对 `kind:'sync'` 直接把结果落盘并将 job 置 `succeeded`，轮询对其短路。这是本功能最大改动点，须在 plan 阶段细化，确保不破坏 grsai 异步路径与重启续拉。
- **设置 UI**：厂商增删改、选当前厂商、每厂商填模型清单与协议类型。

## 统计页
- **落点**：复用预留的 `'api'` 标签或新增 `'stats'` 标签。
- **埋点**：每个 job 终结时追加一条事件到工作区 `.image-flow/stats.jsonl`：
  `{ ts, provider, model, kind('generate'|'edit'), latencyMs, status('succeeded'|'failed'|'violation'), promptTokens?, totalTokens? }`。
  jsonl 持久、可读、可外部分析。
- **耗时**：job 提交 → 终结的墙钟时间（现有 `startedAt`，需补记 `finishedAt`）。
- **成功率**：succeeded vs (failed + violation) 计数。
- **花费**：图片接口通常不返回货币花费。
  - 能返回 `usage` token 的接口记 token；
  - 货币花费走**用户自配单价表**（每图 / 每千 token）估算，UI 明确标注「估算」。
- **聚合展示**：按厂商 / 模型 / 日期出表格 + 简易条形（不引图表库）。

## 待确认决策
- 统计页落点：复用 `'api'` 标签 vs 新增 `'stats'` 标签。
- 花费口径：用户自配单价估算（推荐） vs 仅展示 token / 调用次数、不算货币。
- 埋点存储：`.image-flow/stats.jsonl`（推荐） vs globalState 环形缓冲。
- 多厂商配置是否需要「内置 grsai 预设」一键填好默认节点。
