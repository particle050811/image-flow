# 功能二：收藏夹 + 一键导出 — 设计

> 状态：**设计稿，待审阅**。本文只给设计与数据模型，不含实现代码。
> 日期：2026-06-19 ｜ 同期设计：功能一（AI 命名 edit 任务）、功能三（多厂商与统计页）

## 现状锚点（代码事实）

- 任务产出图片落盘在 `.image-flow/tasks/<毫秒时间戳>/`；素材库扫描在 `src/materials.ts`。
- 已有「同名 MD」约定：图片旁存在同主名 `.md` 描述文件时排序靠前、插入引用时附带描述。
- 任务不会被自动删除（仅空文件夹会，本轮功能一已改为保留）。
- 配置存储：非敏感项进 `globalState`，全项目数据文件统一用 JSON。

## 目标
给产出图片加「收藏」标记，支持**多个收藏夹**分组管理，并能把某个收藏夹一键导出到用户指定文件夹。

## 收藏（按图片粒度，多收藏夹分组）
- **粒度**：按单张图片（产出的图才是价值单元），而非整任务。
- **分组**：支持多个命名收藏夹（collection）。**一张图归属一个收藏夹**——右键「加到某夹」即**移动**（先从其它所有夹移除，再加入目标夹）；左键在当前夹切换。
- **存储**：工作区根 `.image-flow/favorites.json`，结构为 `collections[]`，每个分组有不可变 `id` + 可改 `name` + `items[]`（每项 `uri` **绝对 file Uri 字符串** / `note?` / `addedAt`）。
  - **为什么存绝对 uri 而非相对路径**：素材库收藏的图来自任意外部目录（`materials.ts` 扫描的库可能在工作区外、甚至别的盘符），相对路径表达不了。统一用绝对 file Uri 字符串，与代码现有约定（`TaskImage.uri` 即 file Uri 字符串）一致。
- **当前收藏夹**：作为 `favorites.json` 的**顶层字段 `activeCollectionId`** 存（不进 vscode globalState/workspaceState，落本地 JSON，天然按工作区隔离，符合「全项目数据用 JSON」约定）。左键 ⭐ 加进它。**由显式「设为当前」按钮设定，浏览/切 tab 不改变它**——避免去看别的夹子时左键目标飘忽。该 id 失效时回落到默认收藏夹。
- **默认收藏夹**：始终存在且不可删（删到只剩一个时禁删）。无 `favorites.json`（全新用户）时初始化一个默认收藏夹并设为当前。
- **id 生成**：新建分组用 `c_${Date.now()}`（毫秒时间戳，单机内不会撞）。一旦生成不再变，重命名只改 `name`。
- **悬空处理**：加载时按分组各自过滤掉文件已不存在的项（用户手删任务夹后的残留）。
- **UI**：
  - 任务卡片 / 素材库每张图加 ⭐ 按钮：**左键**切换收藏（已收藏→取消；未收藏→加入当前夹，轻提示「已加入 XX」，不弹窗）；**右键**弹自定义菜单（webview 需 `preventDefault` 屏蔽浏览器默认菜单）选「移动到哪个收藏夹」。
  - 星标态由后端下发：给 `WebviewImage` 增 `favorited?: boolean` 字段，构造 history / libraries 消息时按 `favorites.json` 打标，前端只读不比对。
  - 新增「收藏」标签页（与现有四标签页一致）：顶部一排收藏夹栏（tab/下拉）切换浏览；每个夹子带「设为当前」（图钉）按钮，当前夹图钉高亮；分组可新建 / 重命名 / 删除（删除时提示内含 N 张图，并提供「把图移到默认夹后再删」选项）。
- **写入串行化**：⭐ 是读-改-写 `favorites.json`，连点要串行处理避免丢更新。

## 一键导出
- **只导图**（不导同名 md）：一键导出心智就是拿图去用，混入 md 文本文件反而脏。
- 用 `showOpenDialog`（选文件夹）选目标目录。
- 导出**当前/选中的收藏夹**，把其中图片文件**复制**过去；命名冲突自动去重（追加序号）。
- 可顺带支持「导出某个任务的全部图」。zip 打包留作后续。

## `favorites.json` 示例

```json
{
  "version": 2,
  "activeCollectionId": "c_default",
  "collections": [
    {
      "id": "c_default",
      "name": "默认收藏",
      "createdAt": 1750300000000,
      "items": [
        { "uri": "file:///d%3A/proj/.image-flow/tasks/1750300000000/edit-1.png", "note": "雪山版定稿", "addedAt": 1750300100000 }
      ]
    },
    {
      "id": "c_1750300500000",
      "name": "产品主图",
      "createdAt": 1750300500000,
      "items": []
    }
  ]
}
```

## 数据迁移
旧版 `{ items: [...] }`（无 version / version 1）读到时，自动包成一个「默认收藏」分组、补 `activeCollectionId`、写回 version 2。一次性、无损。

## 数据流
- **左键 ⭐** → `toggleFavorite{uri}`（目标=当前收藏夹）→ 主进程读 `favorites.json`：已收藏（在任一夹）则移除，否则加入当前夹 → 写回 → 回推。
- **右键 ⭐** → 选定分组后 `moveFavoriteTo{uri, collectionId}` → 主进程**从所有夹移除该 uri 再加入目标夹**（一图归一组）→ 回推。
- **设为当前** → `setActiveCollection{collectionId}` → 主进程改 `favorites.json` 顶层 `activeCollectionId`、写回 → 回推。
- **分组管理** → `createCollection{name}`（id=`c_${Date.now()}`）/ `renameCollection{id, name}` / `deleteCollection{id, moveToDefault?}` → 写回 → 回推。
- **导出** → `exportCollection{collectionId}` → 主进程弹文件夹选择 → 仅复制图片文件（重名追加序号）→ 回报结果（成功数 / 跳过数）。

> 涉及的 `shared.ts` 改动：`WebviewImage` 加 `favorited?: boolean`；新增上述出/入站消息类型。

## 待确认决策（已定）
- 收藏粒度：✅ 图片。
- 一图归属：✅ 单收藏夹（可后续放开多归属）。
- 存储：✅ manifest json（`collections[]`）。
- 当前收藏夹：✅ 显式「设为当前」按钮，存 `favorites.json` 顶层（落本地 JSON，不进 vscode state），与浏览解耦。
- 路径存储：✅ 绝对 file Uri 字符串（兼容工作区外的素材库图）。
- 星标回显：✅ 后端给 `WebviewImage` 打 `favorited` 标记，前端不比对。
- ⭐ 交互：✅ 左键切换当前夹、右键移动到指定夹（一图归一组）。
- 导出形式：✅ 复制到选定文件夹、只导图（zip 留后续）。
- 收藏视图落点：✅ 新标签页（与现有四标签页一致）。
