# image-flow

在 VS Code 中构建和管理 AI 绘图。在活动栏侧栏里配置并触发生成，把 Markdown 正文作为提示词调用 nano-banana / gpt-image-2 接口生成图片，自动下载到本地。

## 功能

- 活动栏「Image Flow」侧栏：工作台（配置 + 生成入口 + 素材库）、任务（进行中任务与历史结果）、设置（API Key + 节点 + 缩略图尺寸 + 按模型编辑注入提示词）三个标签页
- 侧栏锁定标签栏最左的 `.md` 作为「生效页面」，对其正文取整篇作为提示词调用接口
- 解析正文中的 `![alt](相对路径)` 作为参考图（图生图），把图片语法替换为模型可理解的有序引用 `[imageN](文件名)`
- **异步提交 + 后台轮询 + 重启续拉**：点生成后立即返回，后台轮询拉结果，VS Code 重启后自动续拉未完成任务
- 生成的图片自动下载到生效 MD 同级、以生成时间命名的 `task-yyMMddHHmmSS-seq` 文件夹
- 右键 `.md` 文件可触发生成或「预览请求」（不调接口、不消耗额度，查看替换后的提示词与请求参数）
- 素材库：手动添加目录 + 按当前 MD 路径各层自动生成的素材库；右键缩略图可把相对引用插入生效页面光标处

## 使用步骤

1. 点击活动栏的 Image Flow 图标打开侧栏，在「设置」页填入 API Key（从 https://grsai.ai/zh/dashboard/api-keys 获取）
2. 在编辑器打开一个 `.md` 文件（侧栏会锁定标签栏最左的 md 作为生效页面）
3. 在「工作台」页选模型/比例/分辨率/并发数，点「生成」
4. 在「任务」页查看进行中任务与历史结果；图片保存在该 MD 同级的 `task-*` 文件夹

## 配置项

配置在侧栏内管理，即时保存，无需改 settings.json：

| 项 | 默认值 | 说明 |
| --- | --- | --- |
| API Key | `""` | grsai API Key（Bearer token），加密存于 VS Code secrets |
| 节点 | 国内节点 | API 节点地址（国内 / 全球） |
| 模型 | `nano-banana-2` | nano-banana-2 / nano-banana-pro / gpt-image-2 / gpt-image-2-vip |
| 比例 | `3:4` | 1:1 / 16:9 / 9:16 / 4:3 / 3:4 |
| 分辨率 | `1K` | 1K / 2K / 4K |
| 并发数 | `1` | 单次生成并发提交的 job 数 |

> 不同模型的尺寸参数处理：nano-banana 系列用比例 + 分辨率；gpt-image-2（非 vip）只用比例（忽略分辨率）；gpt-image-2-vip 只接受像素值，扩展会按所选比例 + 分辨率自动换算。

## 已知限制

- 参考图通过正文 `![alt](相对路径)` 解析；路径可选用 `<>` 包裹以支持含空格/括号的文件名。带 `"title"` 的图片语法暂未特殊处理。
- 素材库目录扫描有深度（3 层）与条目数（500）上限，超大目录可能不会扫全。
